## ⭐ Spotlight — Data Platform & Framework

> **An end-to-end open-source Data Lakehouse ecosystem — from infrastructure to analytics.**

<table>
<tr>
<td width="50%" valign="top">

### 🏗️ [`data-plataform`](https://github.com/VictorLorenzo/data-plataform)

A fully containerized **Data Lakehouse** platform that orchestrates the entire data lifecycle — ingestion, processing, storage, governance, and visualization. A reference architecture for scalable, vendor-independent data platforms.

**Architecture highlights:**
- 🔶 **Medallion Architecture** — Landing → Bronze → Silver → Gold
- ⚡ **Distributed Processing** — Spark cluster with Delta Lake
- 🛡️ **Data Governance** — Unity Catalog + Iceberg
- 🔄 **Orchestration** — Airflow (CeleryExecutor) + NiFi
- 📦 **Storage** — MinIO (S3-compatible)
- 🔍 **Query Engine** — Trino with Iceberg connector
- 📊 **Visualization** — Metabase dashboards

</td>
<td width="50%" valign="top">

### 🧩 [`data-framework`](https://github.com/VictorLorenzo/data-framework)

A reusable **PySpark ETL framework** implementing Delta Lake with Medallion Architecture, enabling standardized and reusable pipelines with built-in data quality controls. Used as a submodule inside the platform.

**Core capabilities:**
- 🔧 `BaseProcessor` / `FileProcessor` / `SQLProcessor`
- ✅ Pydantic-based schema validation
- 📝 Jinja2 dynamic configuration templates
- 💎 Delta Lake 3.2 + Iceberg UniForm support
- 🐳 Dockerized dev environment with Jupyter & Spark UI
- 🧪 Full test suite with pytest + coverage

</td>
</tr>

## 🔁 Data Pipelines

> **Production-grade pipelines built on top of the platform.**

### 🎮 [`igdb-pipeline`](https://github.com/VictorLorenzo/igdb-pipeline) — Game Analytics Pipeline

End-to-end pipeline extracting **71 entities** from the IGDB API, processing them through the full medallion architecture, and serving **10 analytics-ready gold tables**.

```
IGDB API (71 entities) → NiFi (OAuth ingestion) → Bronze (71 raw tables)
    → Spark/Delta Lake → Silver (71 cleaned tables)
        → Gold (10 analytics tables) → Metabase Dashboards
```

**Gold tables:** `game_catalog_enriched` · `company_scorecard` · `engine_adoption_trends` · `genre_popularity_analysis` · `platform_market_share` · `release_timeline` · `franchise_performance` · `multiplayer_insights` · `localization_coverage` · `game_content_scoring`

**Orchestrated by** Airflow | **Governed by** Unity Catalog | **Stored in** MinIO (Delta Lake)
